# CODECHECK Editors mark

Team avatar for the CODECHECK **Editors** GitHub team. Two colours only: white on CODECHECK green `#008033`.

## Files

| File | Use |
| --- | --- |
| `codecheck_editors.svg` | Primary mark. Use at 32 px and above. |
| `codecheck_editors_small.svg` | Simplified mark: one checklist row, heavier strokes. Use at 24 px and below. |
| `png/codecheck_editors_{1024,512,256,128,64,32}.png` | Raster exports of the primary mark. |
| `png/codecheck_editors_small_{32,24,16}.png` | Raster exports of the simplified mark. |

GitHub team avatars are displayed small; upload `png/codecheck_editors_512.png`.

## Design

A checklist board stands in for the head above a shoulder silhouette: the editor is a person who manages the CODECHECK process. The checklist ticks are the CODECHECK tick path used verbatim, at reduced scale.

- Green: `#008033`
- Plate corner radius: 26 px at 256 px (10% of the side)
- Do not recolour, outline, rotate, or add gradients or text.
